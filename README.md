# Country Explorer

## Description
Country Explorer is a Python command-line application that retrieves country information from the countries.dev API. Users can search for countries, filter countries by region, and compare information between two countries.

## Features
- Search for countries by full or partial name.
- Filter countries by region.
- Compare two countries side by side.
- Display population, area, capital, region, languages, and population density.
- Handle API errors and invalid user input.

## Technologies Used
- Python
- Requests library
- countries.dev API

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/legs1205/country_explorer.git
   ```

2. Navigate to the project directory:
   ```bash
   cd country_explorer
   ```

3. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## How to Run

Run the application using:

```bash
python main.py
```

Follow the menu instructions to search, filter, compare countries, or exit.

## API
Country data is retrieved from:
https://countries.dev/countries
